# 📚 Sistema de Biblioteca Virtual

Sistema de gestión de libros desarrollado como proyecto Full Stack, que permite administrar una biblioteca de manera simple e intuitiva.  
Incluye funcionalidades completas de **CRUD**, **búsqueda**, **paginación** y una interfaz moderna y responsive.

---

## 🚀 Funcionalidades

- 📖 **Listado de libros** con paginación y selector de cantidad por página  
- 🔍 **Buscador dinámico** por título o autor  
- ➕ **Registro de nuevos libros**
- ✏️ **Edición de libros existentes**
- 🗑 **Eliminación de libros** con confirmación
- 👁 **Vista de detalle** de cada libro
- 💬 **Mensajes de feedback** para acciones realizadas (guardar, editar, eliminar)
- 🎨 **Interfaz moderna y responsive** con Bootstrap

---

## 🧱 Tecnologías utilizadas

### Backend
- **Java JDK 17**
- **Spring Boot**
- **Spring Data JPA**
- **MySQL**

### Frontend
- **Thymeleaf**
- **Bootstrap 5**
- **HTML5 / CSS3**

---

## 🗂️ Estructura del proyecto

- Arquitectura en capas:
  - **Controller**
  - **Service**
  - **Repository**
  - **Entity**
- Separación clara de responsabilidades
- Uso de `Page` y `Pageable` para paginación
- Manejo de parámetros dinámicos para búsqueda y navegación
